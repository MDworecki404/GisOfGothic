# Widok 2D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tryb 2D geoportalu: ortho z góry z zablokowanym przechyłem i obrotem oraz suwak wysokości cięcia modelu.

**Architecture:** `ViewModeCoordinator` (jak `CameraProjectionCoordinator`) trzyma tryb i wysokość cięcia, wymusza rzut ortogonalny i publikuje zdarzenie `view-mode-changed`. `MapService` implementuje `ViewModeDisplay`: blokuje sterowanie kamerą i przez `WorldSliceController` ustawia płaszczyznę `ClippingPlaneCollection` na tilesetach świata. Komponenty tylko renderują stan z `AppState` i wołają fasadę.

**Tech Stack:** SvelteKit 5, CesiumJS 1.146, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-29-widok-2d-design.md`

## Global Constraints

- Zakaz `any`, operatora `!` i asercji `as`. Importy w `.ts` z rozszerzeniem `.js` (`#lib/...`).
- Bez komentarzy, chyba że funkcja jest skomplikowana; wtedy JSDoc po polsku.
- Obiektów Cesium nie trzymamy w `$state`; komponenty nie importują Cesium.
- Teksty UI po polsku, bez wykrzykników; klasy `material-*` i tokeny z `src/app.css`; elementy dotykowe min. 44×44 px.
- Wysokości w metrach nad elipsoidą (`h`, jak w danych). Domyślnie 2D jest **bez cięcia** (`sliceHeightMetres: null`).
- Parametry adresu: `tryb=2d` (brak = 3D) i `ciecie=<metry>` (tylko z `tryb=2d`). Klucz zakładek `gisofgothic:bookmarks:v1` bez zmian, nowe pola opcjonalne przy odczycie.
- Commity: `<type>: <nagłówek po polsku>` plus **niepusta treść** (commitlint `body-empty`), bez `Co-Authored-By` i wzmianek o Claude. Hook `pre-commit` uruchamia check, lint i testy.
- Dokumentacja w tym samym commicie co zmiana, której dotyczy (`docs/architektura.md`, ADR `0026-widok-2d.md` + wpis w `docs/adr/README.md`).
- Bez wdrożeń produkcyjnych; podgląd tylko `npm run deploy:preview`.

## Review Focus

- `ciecie=abc`, `ciecie=NaN`, `ciecie=Infinity` w linku: ignorowane, widok bez cięcia (test w Task 2).
- `ciecie=50` bez `tryb=2d`: ignorowane, 3D bez cięcia (Task 2).
- Zmiana świata w 2D z aktywnym cięciem: nowy zakres wysokości przycina wartość, a nowy tileset dostaje cięcie (Task 1, Task 3).
- Wyjście z 2D przywraca rzut i FOV sprzed wejścia (np. perspektywa 75°) oraz zdejmuje cięcie (Task 1).
- Klawisz P i wybór rzutu w 2D nie mogą zepsuć trybu (Task 2); stare zakładki bez nowych pól ładują się jako 3D (Task 2).
