# Trasy po sieci waypointów — plan implementacji

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Czwarty tryb narzędzia Pomiary, „Trasa”: najkrótsza droga po sieci waypointów z gry między dwoma punktami, z dystansem, czasem przejścia i profilem wysokości.

**Architecture:** Czyste klasy w `src/lib/services/routing/` (graf, A*, planista) liczą w lokalnych metrach (`LocalPoint`, `LocalProjector`), bez Cesium. `MeasurementCoordinator` dostaje tryb `route` i oddaje planiście start i cel; wynik rysuje istniejącym `showMeasurement`, a profil i czas przejścia liczą się jak dla odległości. Sieć ładuje się leniwie z `waypoints.geojson` przy pierwszej trasie w świecie.

**Tech Stack:** SvelteKit 5, TypeScript, CesiumJS, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-14-trasy-design.md`

## Warunek wstępny (poza tym repozytorium)

Ekstraktor musi dodać `waypoints.geojson` (bez `TOT`) do paczek światów, a pliki trzeba skopiować do `static/data/<gra>/<świat>/` (dane gry nie trafiają do repo). Zadania 1–5 działają na małych danych testowych i nie czekają na to. Zadania 6–8 sprawdza się ręcznie dopiero z prawdziwym plikiem; do tego czasu świat bez pliku zachowuje się jak G3 (tryb wyłączony).

## Global Constraints

- Zakaz `any`, operatora `!` i asercji `as`; zawężaj typy (type guard, walidacja, `satisfies`).
- Importy w `.ts` i `.svelte.ts` z rozszerzeniem `.js`, alias `#lib/…`.
- Nazwy metod to czasowniki mówiące, co kod robi; bez komentarzy, chyba że algorytm jest złożony (wtedy JSDoc po polsku).
- UI nie importuje Cesium; komponenty wołają tylko fasadę (`geoportal`) i czytają `appState`.
- Obiektów Cesium nie trzymamy w `$state`.
- Teksty interfejsu po polsku, sentence case, zgodne z `docs/glosariusz.md`; motyw przez klasy `material-*`, `button-iron`, `choice-card`, bez surowych kolorów.
- Commity: `<type>: <nagłówek po polsku>`, bez `Co-Authored-By` i wzmianki o Claude; jeden commit na zadanie. Nie wdrażaj na produkcję.
- Waypoint `TOT` i punkty z `under_water: true` nigdy nie wchodzą do grafu tras.
- Weryfikacja przed oddaniem całości: `npm run check`, `npm run lint`, `npm run test`, `npm run build`, `npm run test:e2e`.

## Review Focus

- Start i cel w tym samym miejscu (albo przyciągnięte do tego samego węzła): trasa o długości 0, bez błędu i bez zawieszenia.
- Kliknięcie daleko od jakiejkolwiek drogi (próg `MAXIMUM_APPROACH_METRES`): komunikat „w pobliżu nie ma dróg z gry”, bez rysowania linii na siłę.
- Zmiana świata w trakcie ładowania sieci: wynik starszego ładowania jest pomijany i nie psuje nowego świata.
- Świat bez `waypoints.geojson` (HTTP 404, np. Gothic 3): tryb „Trasa” wyłączony z wyjaśnieniem, pozostałe tryby Pomiarów działają.
- Zepsuty parametr `trasa` w adresie (brak liczb, trzy punkty, `NaN`): ignorowany, aplikacja startuje normalnie.
