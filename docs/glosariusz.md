# Glosariusz tekstów interfejsu

Obowiązujące terminy polskiego interfejsu. Teksty piszemy bezosobowo („Zapisano widok”), a do użytkownika
zwracamy się wprost tylko w poleceniach („Kliknij punkt na mapie”). Stany ładowania mają formę
rzeczownika odczasownikowego („Wczytywanie warstwy: {nazwa}”), bez pierwszej osoby („Wczytuję”, „Liczę”).

| Pojęcie | Termin | Uwagi |
| --- | --- | --- |
| Zapisany widok kamery | zakładka (lista: „Zapisane widoki”, przycisk: „Zapisz widok”) | dominujący wariant w aplikacji |
| Włączany zestaw danych na mapie | warstwa | |
| Punkt na mapie | punkt, miejsce | „znacznik” nie występuje w aplikacji |
| Statyczny obiekt świata gry | obiekt; w opisie „voby” | vob to termin społeczności Gothica |
| Wyszukiwarka | wyszukiwarka | |
| Pomiar | pomiar | odległość, pole, współrzędne |
| Tryb widoku | widok 2D / rzut | |
| Postać niezależna | postać | „unikatowa postać” gdy występuje raz |
| Liczba egzemplarzy | sztuki | „Sztuki w świecie” |
| Zadanie | quest | zgodnie z Gothicpedią |

Liczby ze zmiennych podajemy po dwukropku („Miejsca w świecie: {liczba}”), żeby uniknąć odmiany przez liczebnik.
